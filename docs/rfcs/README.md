# RFCs

An RFC (request for comments) here is a design proposal too large for one decision record: a problem, the options, a phased plan, and the questions only the maintainer can answer. It is written before the code, and the maintainer records the answers in its Status section.

- An RFC proposes; it doesn't decide. Each part that is accepted and built becomes a [decision record](../decisions/README.md), and the decision record is what counts from then on.
- An RFC is edited in place while its phases are open, and the Status section says which parts are decided, built or dropped.
- Numbering: `NNNN-short-title.md`, in order.
