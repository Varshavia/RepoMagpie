# 0010 — v0.1 scope

**Status:** accepted (2026-10-03)

## Context
The roadmap's v0.1 held almost every planned feature: example vault, Dataview, `add`, keyword and semantic search, the agent skill, an optional MCP server, recall and an Obsidian graph preset. The new positioning ([0009](0009-positioning-dependency-memory.md)) needs a small first release built around recall. [Strategy](../strategy.md) §6, §7 and §15 set the narrower scope.

## Decision
v0.1 contains:
- **`magpie note <name-or-url> "text"`:** one-line capture of a verdict. Given a GitHub URL, it also fetches the repository's metadata (description, language, license, topics) and detects `SKILL.md` files; a skill URL updates its parent repository's note ([0006](0006-skills-as-searchable-lines.md)). This replaces the earlier `magpie add <url>`.
- **`magpie import <file>`:** the bulk form of `note`, one line per item: `- <url> — verdict: ... | use: ... | avoid: ...`. The free text becomes the draft Verdict, Use when and Avoid when.
- **`magpie search`:** keyword search only.
- **`magpie suggest`:** for a project's manifests and README, or a free-text description, shows matching notes from both journals, Verdict first. No embeddings: magpie narrows candidates by keyword and tags, and the coding agent makes the semantic choice, guided by `SKILL.md`.
- **`magpie adopt <name>`:** copies a note from the personal journal into the project's `.magpie/` and prints the install command. It never installs anything.
- **`magpie recall`** with the Claude Code hook. It informs and never blocks. It never installs a package or hands an install to another tool.
- **Personal and project journals** ([0013](0013-two-journal-scopes.md)).
- RepoMagpie's own `SKILL.md`, which guides the agent for suggest and recall.

`magpie init` (draft notes from manifests) is in v0.1 if time allows, otherwise in v0.2.

Not in v0.1:
- `magpie gaps`: v0.2.
- Semantic search: v0.3.
- MCP server: later ([decision 0002](0002-cli-first.md) already says "later").
- Dataview queries: later.
- Obsidian graph preset and `magpie graph`: marketing material, not scheduled.
- Vet and drift: reduced, v0.2 ([0011](0011-vet-and-drift-reduced.md)).

The note format (Verdict, Use when, Avoid when) and how a note is identified (by package or by repository) are designed in the step 2 spec. Until then, [0005](0005-human-written-usefulness.md) and [0006](0006-skills-as-searchable-lines.md) stand; any change to them needs a superseding record.

## Consequences
- The roadmap's v0.1 milestone and the idea statuses change to match.
- This record decides the v0.1 command set, which step 1.5 listed as open. The step 1.5 interviews may still change it.
- Hook mode at launch covers Claude Code only. Other clients use skill mode ([ideas](../ideas.md), idea 1).
