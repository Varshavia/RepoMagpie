# 0005 — Human-written "when it's useful"

**Status:** accepted (2026-10-01)

## Context
This is RepoMagpie's main differentiator from AI star managers. Search quality depends on concrete, personal usage statements.

## Decision
- The "When it's useful" section is always written by the user.
- The tool may draft every other section, but leaves this one empty.
- A note without it stays `status: inbox` and is ranked below reviewed notes in search.

## Consequences
- More friction per note — so everything else must be automated.
- The journal reflects the user's judgment, which is the product's value.
