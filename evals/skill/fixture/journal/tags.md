# Tags

The eval journal's tag list. Every scenario starts from this journal, unchanged.

- `browser-automation` — driving a browser from code or an agent
- `dates` — dates, times and time zones
- `pdf` — making or reading PDF files
- `postgresql` (postgres) — PostgreSQL and tools built on it
- `testing` — tests and end-to-end checks
- `utils` — small helper libraries
- `validation` — checking input and data shapes
