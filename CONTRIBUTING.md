# Contributing

RepoMagpie is in early development. Nothing is installable yet, and the design and tech stack are still being decided.

## What helps now

- **Ideas and questions.** Open an [issue](https://github.com/Varshavia/RepoMagpie/issues). Tell us how you keep track of the repositories and agent skills you find, and where that breaks down.
- **Problems in the docs.** Open an issue for anything unclear, wrong or contradictory.

## Pull requests

Pull requests are not accepted yet. The design still changes often, so outside code would likely need rewriting. Open an issue instead. This will change once the first release is out.

## Before you start

- [Vision](docs/vision.md): what RepoMagpie is for, and what it is not.
- [Roadmap](docs/roadmap.md): what is being worked on now.

## Security

Don't report vulnerabilities in public issues. See [SECURITY.md](SECURITY.md).
